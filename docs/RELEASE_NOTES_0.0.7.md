# 萌新工具箱 0.0.7

本次更新基于 0.0.6，重点完善 Apex 配置导入导出、快速预设、默认配置恢复和 EA 启动体验。

## 重点更新

- 修复键位录入时再次左击键位按钮无法确认的问题，现在可以正常录入鼠标左键。
- Apex 配置导入与导出改为独立窗口，可按启动项、瞄准、手柄、游戏设置、按键绑定和视频配置分组查看、展开明细并选择需要处理的内容。
- 导出默认对比当前设备与游戏默认值，仅保留实际修改项；按键差异采用稀疏补丁，导入时不会清空目标配置中的无关绑定。
- 完善 Apex 启动项、视频配置、游戏设置和按键绑定的历史记录、恢复、快照导入导出及专用重置流程。
- 修复快速预设重新打开后的状态识别、EA/Steam 启动项序列化、缺失或不完整配置文件初始化，以及失败后的状态与只读保护问题。
- 增强 Apex 游戏设置覆盖范围，补充已验证的玩法、HUD、辅助功能、隐私、键鼠、手柄和音频选项。
- EA 快速启动改用 Windows 原生 COM，通过 Explorer 启动 EA 客户端，修复此前启动访问拒绝问题。
- 更新安装前恢复后台硬件状态，并保留应用退出清理。
- 统一游戏设置说明窗口、工具提示尺寸和通知配色，改善游戏版本信息展示。

## 配置兼容性

仅导出修改过的按键时使用版本 2 快照格式，需使用 0.0.7 导入；仍兼容版本 1 的完整绑定快照。导出预览包含当前编辑草稿，生成默认值用于比较时不会重置游戏文件。

## 下载说明

- `萌新工具箱 0.0.7 安装版.exe`：常规安装版本。
- `萌新工具箱 0.0.7 便携版.exe`：首次启动会将版本化程序缓存到本机，后续启动复用缓存。
- `萌新工具箱 0.0.7 微软商店版.exe`：内置 Microsoft WebView2 离线安装器，文件明显更大；本次作为离线安装选项提供，并不代表已在 Microsoft Store 上架。
