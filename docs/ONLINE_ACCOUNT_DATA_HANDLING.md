# 在线账号客户端数据处理说明

本文只描述当前仓库中可由客户端源码核验的行为，不代表
`apex.0w0.online` 服务端的完整隐私政策。

## 登录与本地存储

- 登录凭据和验证码由系统浏览器中的授权页面处理，不进入 MxTools 的输入框。
- 服务端返回的设备码只暂存在 Rust 进程内存中，不发送给 WebView；授权页地址必须
  与当前 API 地址同源，正式构建固定使用 HTTPS 的 `apex.0w0.online`。
- 授权成功后，客户端会接收账号 ID、邮箱、显示名称和角色；设置页会显示显示名称
  或邮箱。这些账号资料只保留在当前前端状态中。
- access token、refresh token 及其过期时间保存在 Windows 凭据管理器的
  `MxTools/OnlineAccount` 项中，不使用 Web Storage。
- 退出登录时，客户端会尝试通知服务端撤销 refresh token，并删除本地凭据；即使
  服务端请求失败，本地凭据仍会删除。

## 网络数据

在线预设功能会向 API 发送完成登录、读取账号、刷新或注销令牌所需的数据，以及
用户主动浏览、使用、发布、评论或举报预设时提交的相应内容。客户端的 HTTP 请求
由 Rust 侧发出。

## 当前未能由本仓库确认的事项

本仓库没有服务端数据保留期限、账号删除流程、日志用途或第三方共享规则的权威
声明。因此这些事项不能从客户端源码推断，发布在线账号功能前应由服务运营方提供
可访问的隐私政策和账号/数据删除渠道。
