# Apex 默认参数维护

## 当前策略

只维护当前默认参数，Steam 与 EA 共用同一套设置和键位模板。
旧版参数差异只记录，不保留旧模板、按 build 分支、版本白名单或程序/资源指纹拦截。
版本提示仅展示校验记录，不决定是否允许恢复默认；更新模板仍需单独验证参数变更。

画面默认值根据实际硬件、显示模式和 `dxsupport.cfg` 生成，字幕根据游戏语言生成。
保留安装路径、资源结构、硬件、语言、配置格式和参数合法性检查。
不支持的额外 PC 档位覆盖仍在写入前报错，不生成猜测值。

恢复默认先在内存生成三份配置，保存历史后清空当前账户启动项，写入并回读验证。
失败时回滚；无法确认回滚时保留恢复历史。普通预设仍只修改用户选中的项目。

当前模板包含 35 个 settings 值、149 个 profile 值（含语言相关字幕）、108 条键位；
画面生成包含 42 个字段。设备标识和账户名称不写入通用模板。

目标 build 登记为“已适配”；在此之前三个页面均显示“尚未验证适配”。

## 测试与资料边界

`npm run test:apex-video-native` 校验完整设置/画面目录与原生校验器的一致性，
以及 Steam/EA 临时文件中的写入、重新读取和再次重置。
普通测试不依赖游戏安装、外部分析资料或其他项目的目录。

外部分析工具、原始资料和详细报告只存放在独立 Apex 项目。
MxTools 只保留实现所需参数、普通回归测试与本页简短变更记录。
