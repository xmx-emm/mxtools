# Apex 键位编辑约定

- 录键使用游戏配置键名：左方括号为 `[[`，分号为 `SEMICOLON`；
  界面分别显示 `[` 和 `;`。
- 鼠标左、右、中键对应 MOUSE1、MOUSE2、MOUSE3；侧键为 MOUSE4、MOUSE5。
  DOM 的 button 编号不等于游戏键号。
- 默认模板保留 MOUSE3 标记、MOUSE4 战术技能、MOUSE5 终极技能；
  两个技能同时保留 Q/Z 第一槽位。
- 快速预设只管理右键瞄准和滚轮前进/跳跃，不负责补回其它动作。
- 未编辑绑定保留原始行。显示格式调整不应重写其它按键。
- 完整重置后键位、画面和语言相关默认设置立即可用。平台约定见
  [配置一致性修复](APEX_CONFIG_ALIGNMENT.md)。
