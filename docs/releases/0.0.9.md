# 萌新工具箱 0.0.9

- 修复 Apex FPS/性能显示启动项，并同步快速预设。
- 完善 Apex 恢复默认的设置、键位和回读校验；Steam/EA 共用当前参数，旧参数差异仅作记录。
- 修复 PUBG 启动项重复参数、窗口参数及未知参数保留问题。
- 改进在线账号授权链接校验、预设输入校验和桌面链接权限。
- 修复异步确认操作期间弹窗卸载导致的状态问题。
- 优化启动资源加载，完善正式构建的输入、体积和测试检查。
- 便携版新增签名在线更新通道，支持保留自定义文件名的原位替换和重启。

## 更新说明

安装版 0.0.8 可通过应用内检查更新升级。更早安装版需手动下载安装包。
已发布的 0.0.8 便携版需要手动替换一次为 0.0.9，之后可使用便携在线更新。
商店版更新由商店管理。

Tauri 更新签名用于校验更新包来源和完整性，不等同于 Windows Authenticode
发布者证书。Windows 或 SmartScreen 仍可能显示未知发布者。
