# 萌新工具箱 0.0.8

- 启用普通安装版的签名在线更新，支持启动时自动检查、下载进度和确认安装。
- 优先检查 Gitee 国内更新源，网络或清单异常时回退 GitHub；国内下载失败时仅回退到同版本、同签名的 GitHub 安装包。
- 统一更新清单与正式附件文件名，安装包通过签名验证后才启动安装。
- GitHub 发行后自动同步安装版、便携版和签名到 Gitee，国内更新清单在附件校验完成后发布。

从 0.0.7 或更早版本升级，请手动安装一次 0.0.8 安装版；以后更高版本可使用应用内更新。
便携版继续手动更新。离线 WebView2 包较大，保留 GitHub 下载。

Tauri 更新签名用于验证更新包来源和完整性，并非 Windows Authenticode 发布者证书。
Windows 或 SmartScreen 仍可能显示未知发布者。
