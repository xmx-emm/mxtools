# 萌新工具箱 0.1.1

## 本次更新

- Apex 快速预设新增可选鼠标灵敏度写入，范围为 `0.1–20`、步进 `0.01`，支持直接输入或横向拖动。
- Windows 拖动调整会在 Pointer Lock 结束后恢复桌面光标位置；普通点击仍保留输入框的聚焦和编辑行为。
- 优化 Apex 快速预设的展开动画内容、窄窗口布局，以及未选键位的快捷键视觉提示。
- 更新 Apex J58 启动参数静态核对说明，并让更新说明窗口在窄窗口中自适应滚动。
- 修复 PowerShell 便携更新 fixture 的临时签名密码参数兼容性。

## 验证范围

- 前端 lint、完整 Vitest、类型检查、生产构建和 bundle 预算。
- Rust 格式检查、Clippy、锁定依赖测试，以及 Apex 原生视频配置回归。
- 在线更新器对安装版和便携版的签名校验、篡改拒绝及便携替换/重启回归。

正式构建完成后，将在本文件补充安装版、便携版及可选离线 WebView2 包的字节数和 SHA-256。

## 发布说明

Tauri 更新器签名用于更新包完整性校验，不等同于 Windows Authenticode 发布者证书。
若发布附件未取得可信 Authenticode 签名，Windows 可能显示未知发布者；请从正式发行页
下载并按页面提供的 SHA-256 校验文件。
