# 萌新工具箱 0.1.2

## 本次更新

- Apex J58 完成启动项、画面配置、游戏设置、键位以及 Steam/EA 配置文件写入、回读、重新打开和重置的全量静态校验，共 47/47 项；三个相关页面统一显示“已适配”。
- Apex FPS 启动项兼容当前 `+fps_max` 格式，修复旧 `-freq` 组合导致的输入框不显示或写回异常。
- 优化 Apex 启动项列表展开动画、FPS 控件尺寸及悬停状态，减少标题漂移和亮度闪变。
- 修复嵌套控件 Tooltip 被外层行标题覆盖时的闪烁问题。
- 调整顶部快捷入口和紧凑按钮文字的垂直对齐，并补充对应契约测试。

## 验证结果

- 前端 lint、完整 Vitest、类型检查、生产构建和 bundle 预算检查通过。
- Rust 格式检查、Clippy、锁定依赖测试和 Apex 原生视频配置回归通过。
- 安装版与便携版在线更新、签名校验、篡改拒绝、真实 NSIS 升级和便携版替换验证由 GitHub Windows Runner 执行。
