# 萌新工具箱 0.1.3

## 本次更新

- Apex 切换启动账户时，如果当前账户的启动项有未保存的修改，会先提示“保存并切换 / 放弃修改 / 取消”，保存失败时留在当前账户，避免修改被静默丢弃。
- 修复 Apex 启动项在账户快速切换时可能误报加载成功的问题。
- 修复导入配置快照、应用快速预设后启动项立即显示“有未保存修改”的误报。
- 应用启动项后会通知其他已打开的 Apex 窗口同步刷新。
- 语音语言配置缺失时不再导致 Apex 页面报错。
- 配置历史清理失败时写入后端日志，便于排查。
- 开发热更新时正确注销后台运行状态的事件监听。

## 验证结果

- 前端 lint、完整 Vitest、类型检查、生产构建和 bundle 预算检查通过。
- Rust 格式检查、Clippy、锁定依赖测试和 Apex 原生视频配置回归（47/47）通过。
- 安装版与便携版在线更新、签名校验、篡改拒绝、真实 NSIS 升级和便携版替换验证由 GitHub Windows Runner 执行。
