# Apex 游戏设置参考

设置目录位于 `src/data/apex_game_settings.ts`，写入校验位于
`src-tauri/src/game/apex_settings.rs`。仅开放完整菜单映射已确认的选项。

## 存储约定

- 武器对话使用 `dialogue_cat_weapon_flavor=0/1`。
- 聊天连接功能使用 `hud_setting_accessibleChat=0/1/2/3`，分别为关闭、
  提示文字、语音、文字和语音。游戏语言可能影响菜单可见性。
- 传奇、标记、广播对话使用 flavor/important 双键，三档为 0/0、0/1、1/1。
- 激光颜色使用 `R + (G << 8) + (B << 16)`；切回默认保留上次自定义颜色。
- 鼠标和手柄的一般瞄准灵敏度只修改各自第 0 倍镜槽位，不广播到全部槽位。
- 浮点滑块保留有限小数，不按界面整数显示强制取整。
- 快照不移植本机音频输入、输出设备标识。
- 最小冲刺镜头晃动写 1，重置为正常值 0。保持瞄准匹配 `+zoom`，
  默认右键使用 `+toggle_zoom`。

## 编辑与验证

键位使用两个配置槽位，配对的按住绑定共同保留，修改前检查输入冲突。
普通设置修改保留未编辑键和未知值。待确认项保持只读，见
[待确认设置](APEX_SETTINGS_REVIEW_AUDIT.md)。

Steam/EA 的账户、启动项文本和语言发现分别处理，见
[平台边界](APEX_CONFIG_ALIGNMENT.md)。自动测试验证隔离文件中的写入和读取，
游戏内效果需要分别验收。
