# 下载管理

入口位于导航栏“设置”上方，管理本次应用运行中的 Apex Steam / EA 语音下载。

点击入口先显示侧边浮窗，保留当前页面；浮窗内可切换队列和已结束任务。
右上角放大图标打开完整下载页面。点外部、Esc或关闭按钮收起浮窗，
不会停止下载。浮窗与完整页面共用任务操作和启动器退出确认。

- 队列由原生后端串行调度，关闭页面不停止任务。
- 支持暂停、继续、取消、重试、筛选、刷新、清理完成记录及打开语音目录。
- 暂停或取消活动任务会明确确认退出对应启动器，保留文件；继续时重新提交下载，
  由启动器校验和复用文件。不是工具自行实现的字节级断点续传。
- 任务历史仅描述当时的完成情况。重新打开下载对话框会重新检查语音文件，
  不把历史“已完成”当作目前仍已安装。
- Steam 控制台不提供稳定的连续字节进度，显示不确定进度直到收到目标目录的
  完成消息。文件预分配大小不作为百分比或完成依据。
- EA 的字节进度只接收目标游戏数据；JSON桥接错误和还原语言失败会显示失败。
- 队列和历史为当前应用会话数据，不跨应用退出恢复；暂停EA后语言可能暂时
  保持切换状态，继续任务时再恢复原语言。

自动测试覆盖队列串行、暂停确认、不同任务进度隔离、文件删除后重新打开、
Steam完成消息目标匹配和EA带空格JSON解析。页面已使用模拟队列进行浏览器检查。
实际启动器传输及暂停后文件复用仍需 Steam/EA 实机验收。
