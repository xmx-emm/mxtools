## [Unreleased]

当前候选版本为 `0.0.6`；在人工验收、标签和正式发布完成前，不将其记录为已发布版本。

### 新增

- **APEX Q / OCR**：接入本地 PP-OCR 识别流程，支持 Steam 最新截图、手动截图、ROI 校准、识别结果预览、置信度展示、悬浮结果窗和运行时模型下载。
- **Apex 配置管理**：补充游戏玩法、HUD、辅助功能、隐私、键鼠、手柄、音频和按键设置，并加入已验证选项的说明与色盲模式预览。
- **Apex Miles 语音包**：Steam/EA 支持通过本机客户端 CEF 一键下载；两端共用单任务互斥与进度事件，并在确认没有运行中的游戏后才重启客户端。
- **Apex 历史与恢复**：为启动项、视频配置和游戏设置增加版本化历史、事务写入、快照导入导出、可撤销恢复和 Apex 专用重置。
- **多窗口与托盘**：新增 APEX Q 工作台、OCR、设置和悬浮窗入口，支持从托盘及主窗口直接导航。
- **系统修复工具**：新增修复工具目录，Microsoft Store、OneDrive、空白图标、网络和 Apex 启动修复各自运行在独立窗口；检查与修复动作均取自允许列表，管理员操作合并为一次 UAC 请求。
- **游戏体检**：新增游戏环境检查页面，汇总评分、网络指标与分组检查项，并提供允许列表内的一键优化。
- **性能模式**：新增默认关闭的性能模式开关，可关闭页面与浮层动画以及主题过渡。
- **Beta 功能门禁**：增加默认关闭的 Beta 功能开关，统一控制未完成工具在导航、搜索、快捷键、托盘和直接路由中的可见性。
- **Razer 轮询率(Beta)**：新增独立的 Razer 鼠标轮询率工具，支持能力验证、按设备记忆和前台游戏自动切换。
- **在线账号与预设库(Beta)**：新增浏览器设备码登录，令牌仅保存在 Windows 凭据管理器；支持浏览、使用、发布和举报在线 Apex 预设。
- **发布产物**：一次构建生成普通安装版、缓存式便携版和内置 WebView2 离线安装器的微软商店版，并保留体积与 bundle 报告。

### 变更

- **名称与契约**：将未发布的 Alter Q 全面更名为 APEX Q，并统一窗口、路由、事件、IPC、存储键和错误码命名。
- **APEX Q 悬浮窗**：支持自定义位置、尺寸和不透明度，使用显示器相对物理坐标改善多显示器与混合 DPI 下的位置保存和恢复。
- **Apex 页面状态**：账户、启动项、视频配置和游戏设置采用独立加载状态及请求代次；保留脏编辑并静默刷新干净缓存。
- **界面一致性**：统一 Apex 与 PUBG 的紧凑分段控件、导航尺寸、搜索控件、主题色、加载状态和无障碍交互。
- **Apex 游戏设置**：有上下界的数值项改为紧凑滑块加数字输入，与游戏内控件一致。
- **通知与页面切换**：缩小 Toast 密度以适配工具窗口，页面进场分层淡入而不做反向离场位移。
- **导航与国际化**：按实际标签测量导航宽度，改善拖动与页面切换动画；语言包改为按需异步加载并增加中英文键值一致性检查。
- **性能与安全**：裁剪依赖特性，使用 Windows TLS 流式下载 OCR 资源，增加下载校验、IPC 错误边界和前端 bundle 硬预算。
- **Apex 文本与官方客户端对齐**(对照当前构建 `R5pc_r5-300_J57` 的官方简中文本,逐项经用户确认):
  - 视频设置:「纹理质量」更名「纹理串流预算」并附官方 VRAM 注释(无/很低 2GB/低 2-3GB/中 3GB/高 4GB/很高 6GB/超高 8GB);「很高/超高」不再是预设外档位;「双缓/三缓」改「双缓冲/三重缓冲」;「动态阴影数量上限」改「动态点光源阴影」(该键在当前版本已有菜单属主);「环境光遮蔽」改「环境光遮蔽质量」;「音量」改「主音量」。
  - 游戏设置:「NVIDIA 低延迟/AMD 低延迟」改为游戏内名称「Nvidia Reflex」「AMD Anti-Lag 2」;「视野技能缩放」开关方向与游戏菜单对齐(新增 `invertToggle` 展示反转,存储键 `fov_disableAbilityScaling` 语义不变);响应曲线「传统」改「经典」;「菜单光标速度/UI 模式/接听语音聊天音量/背景声音」等名称与官方一致;「非好友」改「无好友」;「击杀者」改「仅击杀者」。
  - 说明文本:疾跑控制、翻越加速提示采用官方分档行为说明。

### 修复

- 修复 Apex 账户切换、外部配置变更、快速预设和快照导入中的陈旧状态、跨范围写入与失败回滚问题。
- 修复 PUBG 配置加载门禁和 Apply 重入问题。
- 修复输入法、RDP、防火墙、端口转发和 Windows 用户刷新中的错误传播与竞态问题。
- 修复托盘提示残留、全局快捷键状态、反馈链接长度、搜索控件及多处窄窗口布局问题。
- 修复快速预设在 `settings.cfg` 缺失或不完整时"只写入少量绑定"的问题:现在先从内置的当前构建默认键位模板初始化完整文件,再应用所选优化(绑定不会被游戏补齐,因此模板带完整默认键位集)。
- 修复绑定变更校验把游戏默认文件中合法的同命令同上下文键位误判为冲突的问题(如 ESCAPE+START 都开菜单、F6+F8 都是调试标记):现在只在本次变更新建/修改造成重复时才报错,不再误伤默认模板和真实游戏文件。
- 修复重置后再应用快速预设报 `MOUSE2` 绑定冲突的问题:应用前改为强制从磁盘重读启动项、画面和键位,避免窗口里的过期状态在已有键位上重复新建。

### 变更

- **Apex 重置为内置默认模板**:`videoconfig.txt`、`settings.cfg` 与 `profile.cfg` 现在都直接写入内置的当前构建默认模板(立即完整、可在工具内继续编辑)。画面分辨率沿用重置前的当前值,避免写错显示器。模板经当前构建实测核实。

### 移除

- **Apex 失效启动项**(对照当前构建 `R5pc_r5-300_J57_CL11457258_2026_08_19_15_40` 逐项实测核实):
  - 优化鼠标四件套 `+m_rawinput 1` / `-noforcemaccel` / `-noforcemspd` / `-noforcemparms`(原始输入在当前版本恒为开启,相关 convar/flag 均已从游戏二进制删除)
  - 强制禁用垂直同步 `-forcenovsync`(flag 已不存在;垂直同步请用游戏内视频设置)
  - 禁用布娃娃 `+cl_ragdoll_collide 0`(convar 已不存在)
  - 图形 API 切换 `-anticheat_settings=SettingsDX11.json / SettingsDX12.json`(DX11 已被官方移除,当前仅有 DX12;且 EAC 目录只剩 `Settings.json`,该参数引用的文件不存在)
  - 限制顶点着色器数量 `-limitvsconst`(flag 已不存在)
  - 强制预加载 `+cl_forcepreload 1` / `-preload`(两者均已不存在)
  - 渲染多线程模式 `+mat_queue_mode 2`(convar 已不存在;此前已在目录中停用,本次确认后移除残留代码)
  - 锁帧参数中的 `-freq X`(flag 已不存在;锁帧现在只写 `+fps_max X`,既有的窗口/无边框要求暂保持不变,待验证后另行调整)
- 旧启动串中仍含上述 token 时,它们会原样落入"自定义启动项"输入框,便于手动清理。

## [0.0.5] 2026-7-6

### 新增

- **Apex 视频配置**：新增视频设置页面，可读取并应用游戏内 `videoconfig.txt` 配置（窗口模式、分辨率、垂直同步、抗锯齿、伽马、动态分辨率、模型/纹理/阴影/贴花/CSM、SSAO、体积光、布娃娃等）
- **Apex 页面切换**：Apex 页面支持「启动项」与「视频配置」两种视图切换
- **Apex 快速预设**：新增快速预设对话框，可一键应用比例、分辨率、锁帧、启动项及视频配置组合
- **Apex 宽高比预设**：新增 1:1、2:1、5:4 等更多比例预设
- **设置页**：新增调试模式开关，控制详细日志输出

### 变更

- **Apex 模块**：重构游戏功能目录结构（`launch` / `video_config` / `preset` 分区），统一比例、分辨率、锁帧等通用预设组件
- **Apex 快速预设**：支持视频配置独立开关，启动项与视频项双列展示；优化预设对话框布局
- **Apex 视频配置**：优化 SSAO 质量与布娃娃相关选项；改进伽马预览与 DVS 锁帧滑块交互
- **导航栏**：优化侧边导航布局与面板宽度拖拽调整

### 修复

- 修复 Apex 启动项解析时无限帧率（`+fps_max unlimited`）识别问题
- 修正黑边容忍阈值（`mat_letterbox_aspect_threshold`）配置

## [0.0.2] 2026-3-10

### 新增

- **关于页**：添加腾讯频道、GitHub、项目地址等链接,链接统一放在 `src/data/url_other.ts`
- **Apex 启动项**：新增 NEW 角标标识新特性(比例、强制分辨率、大厅 FPS、优化鼠标),点击或勾选后隐藏并持久化记录
- **设置页**：添加「清除持久化数据」按钮,可重置主题、语言、Steam 用户、上次页面等设置
- **Apex 启动项**：支持比例(Aspect)、强制分辨率(ForcedResolution)、大厅 FPS(LobbyFps)、优化鼠标(InputMouse)等新参数
- **多窗口同步**：使用 `@tauri-store/pinia` 替代 `pinia-plugin-persistedstate`,实现 settings、style、steam 等 store 的跨窗口同步

### 变更

- **关于页**：优化主题适配,增大弹出窗口尺寸(750×600)
- **路由**：仅在主窗口恢复上次页面,避免子窗口(如关于页)误跳转
- **Store**：统一 store 命名,修正 `portForwarding`、`windowsUser`、`rdp` 等 store id
- **版权信息**：更新为 © 2025-2026
- **关于页**：版本号改为从 `@/env` 动态获取
- **页面布局**：移除资源管理器和设置页的宽内容包裹类
- **Apex 配置**：更新启动项配置,新增相关参数

### 修复

- **路由**：修复非主窗口启动时错误恢复上次路由的问题

### 重构

- **Store**：将 user store 重命名为 windows user store,并更新相关引用
- **Apex**：移除调试用 console 日志
